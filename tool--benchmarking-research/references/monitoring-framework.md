# Benchmarking Monitoring Framework

## Cadence Recommendations

| Industry velocity | Recommended cadence |
|---|---|
| Fast-moving (tech, digital products, consumer) | Quarterly or semi-annual |
| Moderate (manufacturing, professional services) | Annual |
| Slow-moving (regulated industries, infrastructure) | Annual to biennial |

## Monitoring Framework

For each priority gap identified in Phase 9:
1. **Leading indicator**: what metric will show early movement before the lagging outcome changes? Track monthly.
2. **Lagging outcome**: the benchmark metric itself. Track on the re-benchmark cadence.
3. **Owner**: who is accountable for movement on this gap?
4. **Re-benchmark trigger**: define the condition (not just the date) that should prompt an unscheduled re-benchmark — e.g. a competitor announces a major product change, a regulation shifts, the leading indicator moves sharply.

## At Re-Benchmark, Ask

- Did the gaps close, hold, or widen? For each, state why.
- Did the peer group shift? Are the original comparators still the right ones?
- Were the Phase 9 recommendations actually implemented? If not, is the gap still meaningful?
- What new gaps emerged that were not visible in the original benchmark?
