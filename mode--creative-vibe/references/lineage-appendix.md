# Lineage Appendix

Source: THE MANIFESTO OF BALANCED CREATION, Appendix A. These are teachers, not templates. **Study the decisions behind the work, not the appearance of the work.** The common mistake is copying the surface (the grid, the Helvetica, the geometric shapes); the deeper practice is understanding why those choices were made, for what problem, under what constraints.

| # | Thinker/movement | Core belief | Extract | Question to ask |
|---|---|---|---|---|
| 01 | **Bauhaus** | Design should improve everyday life; art and industry shouldn't be separate | Function before ornament, universal language, geometry as foundation, experimentation | Does this solve a real problem? Is the form honest? |
| 02 | **Josef Müller-Brockmann** | Design is a structured communication system; the grid creates clarity | The grid as invisible architecture, objective communication, mathematical relationships | What is the underlying structure? Does every element relate to something else? |
| 03 | **Armin Hofmann** | The designer's role is discovering the essential | Maximum meaning with minimum elements, contrast creates attention, visual intelligence | What can disappear? Is the contrast intentional? |
| 04 | **Max Bill** | Beauty can emerge from logic | Proportion, systematic creativity, universal forms | Are proportions intentional? Does the composition feel balanced? |
| 05 | **Paul Rand** | Design must communicate an idea, not just an appearance | The idea comes first, simplicity creates memory, personality within structure | What is the central idea? Can it be expressed more simply? |
| 06 | **Picasso / Cubist thinking** | Reality is not singular — there are multiple ways of seeing (studied as philosophy, never reproduced as style) | Multiple perspectives, deconstruction, reconstruction | What perspective is missing? Is there another way to understand this? |
| 07 | **Dieter Rams** | Good design improves life without demanding attention | The ten principles: innovative, useful, aesthetic, understandable, honest, unobtrusive, long-lasting, thorough, environmentally responsible, as little design as possible | (Apply the ten principles directly as a checklist) |
| 08 | **Otl Aicher** | Design should help humans move through complexity | Universal symbols, information clarity, visual systems, human-centered communication | Can a stranger navigate this without being told how? Does the system hold at scale? |
| 09 | **Kenya Hara (Ma)** | Emptiness is not absence — it's a vessel that holds more than a full space can | Ma (the interval/pause/gap), whiteness as a receptive state not a color, senses before graphics, emptiness invites participation | Is the emptiness doing work, or just unused? Does this feel like a material, or a screen? |
| 10 | **Christopher Alexander** | Recurring problems have recurring solutions that connect into a language, not a catalogue | A pattern = problem + context + solution; patterns compose into a language; wholeness; the quality without a name | What problem does this pattern solve, in what context? Is the whole alive, or only assembled? |
| 11 | **Massimo Vignelli** | Design is one discipline regardless of medium (book, sign, chair, screen) | Discipline over invention, semantics, appropriateness, timelessness as method | Would this decision hold in a different medium? |
| 12 | **Edward Tufte** | Above all else, show the data — distortion is a moral failure, not a stylistic one | Data-ink ratio, graphical integrity, small multiples, layering | What comparison is this display for? Does visual proportion match numeric proportion? |
| 13 | **Bruno Munari** | Design is a teachable method; rigor and play are not opposites | Define the problem before designing, decompose into sub-problems, play as method, simplification as the hardest work | Have I defined the problem, or accepted someone's description of it? |

## Contemporary translation (historical principle → modern application)

| Historical principle | Modern application |
|---|---|
| Swiss grid | Responsive digital systems, layout primitives |
| Bauhaus function | Product usability, honest interaction |
| Hofmann reduction | Minimal interfaces, deliberate contrast |
| Bill proportion | Type scales, spacing scales, token ratios |
| Rand simplicity | Brand clarity, memorable identity |
| Rams honesty | Ethical technology, no dark patterns |
| Cubist perspective | Data visualization and narrative structure |
| Aicher systems | Design systems, wayfinding, iconography |
| Hara ma | Whitespace as substance, calm interfaces, warm neutrals |
| Alexander patterns | Component libraries, pattern languages, tokens |
| Vignelli discipline | One language across web, native, print, motion |
| Tufte integrity | Dashboards, analytics, any numeric display |
| Munari method | Design process, problem framing, prototyping |

## The reframe (from the source document)

Do not ask "how can we make something that looks Swiss?" — ask "how would a Swiss designer approach this problem?"

Do not ask "how can we copy this style?" — ask "what principles created this result?"

**Final rule: borrow wisdom, never borrow identity.**
